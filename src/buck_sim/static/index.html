Buck Converter Simulator

1 Upload files

LTspice schematics (.asc): export a netlist first with View → SPICE Netlist.

Netlist required

The complete buck converter (.cir, .net, .sp).

IC model files optional

Only for the controller IC and vendor semiconductors (MOSFET, diode) that the netlist .includes. Resistors, capacitors and inductors need no model: SPICE simulates them as ideal parts from the values in the netlist.

BOM optional

Bill of materials as CSV (export from Excel/KiCad/Altium). Reference only: compared with the netlist values and added to the report. It does not change the simulation.
